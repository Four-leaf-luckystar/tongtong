💡 自定义提示词的用处

自定义提示词允许您在底层 System Prompt 中注入特定的规则、世界观或行为准则，从而更精准地控制 AI 的回复风格（例如：强制某种口癖、设定特定场景限制）。

🛠️ 变量使用教程

点击输入框上方的胶囊，可快速插入以下变量，系统会在对话时自动替换为真实数据：

  • ${charname}：当前聊天的角色名称。
  • ${username}：您当前使用的User名称。
  • ${time}：当前的系统时间。

⚙️ 底层拼接说明

系统在发送请求时，会自动将您的自定义提示词与内置的 JSON 数组格式要求拼接。因此，您无需在自定义提示词中重复声明 JSON 输出格式，只需专注于角色行为和设定的引导即可。
